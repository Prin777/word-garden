# Word Garden 项目讨论与决策

## 词库与学习流程

- 英文项目名为 **Word Garden**，仓库名为 `word-garden`，中文界面名称为“单词小径”。
- 本地第一版从选定的 Anki 雅思卡包导入 3,610 个不同单词。卡包、导入数据、原始音频和用户 SQLite 数据库留在本机。
- 认词和听音使用独立学习记录。FSRS 初始使用默认参数，目标保留率 90%。配对最后一组无需判断的选项不计独立成功，首次被动完成安排短期复习。当天答错的词最多追加一次巩固，保留原始作答。

## 发音方案

- 原始音频由网站本地提供，共 3,610 个文件、约 29.6 MB，口音尚未逐词核对。
- 比较过系统本地语音和 Piper。系统语音依赖浏览设备上已安装的语音。Piper 可统一模型和口音，安装好运行环境和模型后由本机 CPU 合成。
- **实时版**在网站启动时开启 Piper 进程，点击时生成短 WAV，返回给浏览器后清理临时文件。模型和配置常驻复用。300 毫秒是待实测的点击至出声目标。
- **批量版**启动时为整个本地词库补齐 WAV。已生成的文件可复用，播放时直接读取 `data/piper-media/`。以每词 1–2 秒估计，22.05 kHz 的 16 位单声道 WAV 约 159–319 MB，若后续改成 48 kbps MP3 则约 22–43 MB。当前实现保存 WAV。
- 两种 Piper 模式默认使用约 63 MB 的 `en_US-lessac-medium` 模型，只有准备模型和程序时需要联网。同拼写多读音的词需抽查，当前 Piper 按拼写合成。当前优先在 Windows 本地运行网站。

## 重新导入本地词库

Windows 下将自己的 Anki 卡包放到 `research/ielts-sample.apkg`，将卡包内的 `collection.anki2` 和 `media` 清单提取到 `research/`，执行 `npm run import`。导入脚本生成 `data/words.json`、媒体映射和原始音频。网站首次在空词库启动时加载该 JSON，已有 SQLite 词条编辑会保留。第三方词库、音频与模型的使用权限以各自许可为准。
