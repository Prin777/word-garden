# 页面草图

2026-11-10。低保真布局，仅用于确认入口、信息层级和流程，不代表最终配色或视觉效果。

## 页面流程

用户选择 → 首页 → 今日词汇（可跳过）→ 选择模式练习 → 结果页

首页可直接进入任一练习模式；有未完成会话时可以继续。后台独立入口，访问限制在部署阶段处理。

## 4. 拼写配对

```text
┌──────────────────────────────┐
│ ‹ 返回    拼写配对     2 / 5 │

│                              │
│ [ emperor   ] [ 缺乏       ]│

│ [traditional] [ 皇帝；君主 ]│
│ [ lack      ] [ 精确的     ]│
│ [ ……已完成… ] [ ……已完成… ]│
│                              │
│ 选中：边框高亮               │

│ 正确：淡出，原位置保留       │
└──────────────────────────────┘
```

说明文字用于草图解释，正式练习页不重复展示全部状态说明。组完成后出现“下一组”，不自动立刻跳转。

## 5. 听音配对

```text
┌──────────────────────────────┐
│ ‹ 返回    听音配对     1 / 5 │
│ 点左侧听读音，再选择中文     │
│                              │
│ [ 🔊  1     ] [ 传统的     ]│
│ [ 🔊  2     ] [ 缺乏       ]│
│ [ 🔊  3     ] [ 精确的     ]│
│ [ 🔊  4     ] [ ……已完成… ]│
│ [emperor  ✓ ] [ 皇帝；君主 ✓]│
│                              │
│ 点击同一按钮可重复播放       │
└──────────────────────────────┘
```

编号仅区分按钮，不透露拼写；答对后才出现英文。播放新词时停止前一个音频，避免重叠。

## 8. 手机与电脑适配

手机保持两列配对，中文按钮支持换行，按钮区域保持可点击。电脑将练习区居中、限制宽度；总览与后台可利用较宽区域。所有正确、错误状态同时用图标或文字表达，不只依赖颜色。
