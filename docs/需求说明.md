# 单词配对学习网页：第一版需求说明

版本：0.1，2026-11-10。状态：待页面与细节确认，尚未开始应用开发。

## 1. 目标与交付顺序

提供类似多邻国单词配对的学习体验，练习英文认读与听力，并保存个人学习记录、安排复习。

1. 本地网页：词库整理、用户选择、今日词汇、两种配对模式、学习记录与复习。
2. 服务器版本：生成 Docker 镜像，部署到已有 Docker 的飞牛服务器；持久保存数据，提供备份说明。
3. 安卓 APK：联网连接同一服务，与网页共用学习记录；不要求离线学习。

服务器已有公网 IPv6、DDNS 和域名，用户手机可访问。域名、HTTPS、端口和后台网络限制在部署阶段落实。

## 2. 范围与决定状态

### 已确认

- 第一版提供拼写配对、听音配对，用户手动选择，分别记录表现。
- 每组全部完成后进入下一组；默认 5 个词，可配置 5–10 个。最后一组允许不足配置数量。
- 每天默认 10 个新词，可配置。
- 使用已调查的 IELTS Anki 卡包作为初期内容来源；PTE 和词库切换后续增加，暂不处理跨词库进度合并。
- 采用美音；配对优先核心中文释义；同组不出现相同中文答案。
- 答错短暂标红，继续选择，不直接揭晓；答对后淡出并保留位置。
- 听音配对成功后展示英文拼写。
- 中途退出保存当前组，重新进入可继续；错误记录保留。
- 初期有一个默认用户；支持后台编辑用户，前台仅选择用户，不做密码登录；每人记录独立。
- 先采用 FSRS 与配对评分适配方案，保留原始作答记录，实际使用后调整。
- 后台访问限制暂缓，不阻碍本地版本。

### 本文采用的建议默认值，可在评审时修改

- 简洁、轻游戏化，手机竖屏优先，兼容电脑。
- 北京时间凌晨换日；当天新词名单固定，两种模式共用名单。
- 每日新词按不同单词计算，两个模式重复练同一词不重复计数。
- 未完成新词次日优先安排，不累计额外新词额度；旧词复习另计。
- 到期复习优先，之后引入新词；完成目标后可继续复习或主动加学。
- 用户的每日目标与每组数量独立保存。
- 今日词汇可随时查看；查看和播放不计作完成练习。

## 3. 页面与操作

### 用户选择

展示用户列表；选择后进入其首页。当前用户在首页可切换。后台可新增、改名、停用用户；停用保留历史，第一版不提供直接清空历史的快捷操作。

### 首页

展示当前用户、今日新词目标与进度、待复习数量；提供今日词汇、拼写配对、听音配对入口。有未完成练习时优先显示继续练习，并标明模式。两种模式进度分别展示，不能把认词成功当成听音成功。

### 今日词汇

分为今日新词、今日复习。单词列表可展开详情：英文、美音按钮、音标、词性、核心中文、完整中文和英文释义、已有例句、学习状态及各模式错误次数。缺失字段不伪造，例句翻译不属于第一版必备数据。

可跳过预习直接练习；不因查看详情修改掌握状态。待复习列表随完成情况更新，新词名单当天固定。

### 配对练习

- 顶部显示模式、当前组进度、返回入口。
- 拼写模式左列英文，听音模式左列喇叭按钮；右列中文核心释义。两列独立打乱。
- 点击左项选中，听音模式同时播放；点击右项提交配对。可重新点击左项播放或改选。
- 答错短暂标红后继续；答对淡出、禁用，保留位置，听音项显示英文。
- 一组全部配完显示下一组入口；全部计划完成进入结果页。
- 同组无重复英文或相同中文答案。抽不到足量的合法组合时允许缩小组；只剩一个词时可配对完成，但不据此延长复习间隔。
- 返回、刷新、关页后恢复本组顺序和完成状态；已确认作答不重复累计。网络中断应提示并允许重试，未保存结果不伪装成保存成功。

### 结果页

展示本次新词数、复习词数、首次正确率、错词及继续复习/今日词汇/首页入口。首次正确率排除仅剩最后一对的被动完成；没有有效评价时显示“暂无”。

### 后台配置

用户管理；各用户每日新词目标、每组数量；词库查询与内容修正；词库完整性问题列表。第一版针对选定卡包导入，不承诺支持任意 Anki 模板。FSRS 参数默认不向普通学习页面展示。

## 4. 学习与复习

以用户 × 单词 × 模式维护独立学习状态，保存下次复习时间。默认参数启动 FSRS，目标保留率建议 90%；积累记录后再考虑个性化优化。这个目标是算法参数，不是实际掌握率保证。

配对评分初版规则：

1. 某词在本次复习第一次选错，记失败；之后改对不覆盖失败。
2. 第一次选对且仍有多个候选，记该模式识别成功。
3. 最后一对仅记录完成，不作为延长复习间隔的独立证据。
4. 每次误配记录所选英文与所选释义；错误归于主动选中的英文，不自动惩罚被误选释义对应的另一个词。
5. 同一次复习的纠正点击不重复提交 FSRS 评价；后续重新安排的巩固练习另行记录。
6. 当日错词隔几组重现；短时巩固不能被当成多次跨天成功。具体短时调度在实现时采用统一规则并保留记录。

以上是产品适配方案，未经过本应用实测。不得用一次配对成功直接宣称“已掌握”。

## 5. 词库准备

来源：https://github.com/huangzhenghz/Anki-IELTS/releases/tag/v1.0.0

已实际读取 3,611 条笔记、3,610 个不同单词；无中文缺失，17 条缺音标、28 条缺英文释义；每条音频引用都有对应媒体文件，但未逐个听音验证。

整理要求：保留原始完整释义，增加可编辑核心中文释义；合并重复词；清理 HTML；核对美音及音标一致性；追踪缺失与待核对字段。无可用音频的词不进入听音练习。词库更新保持稳定标识，不重置用户进度。

词库、音频独立于应用发布物维护，当前按个人学习使用，不把此卡包随公开镜像或 APK 分发。详见 ../research/anki-vocabulary-audit.md。

## 6. 数据设计约束

本节确定数据职责，不锁定数据库或开发框架。

| 数据 | 必须保存的内容 |
|---|---|
| 用户 | 标识、名称、状态、个人学习配置 |
| 单词 | 稳定标识、英文、词性、核心与完整释义、例句、来源、核对状态 |
| 发音 | 单词关联、口音、音标、音频位置、来源信息 |
| 每日计划 | 用户、日期、新词名单、目标快照、完成状态 |
| 模式学习状态 | 用户、单词、模式、错误次数、FSRS 状态、下次到期时间 |
| 练习会话与分组 | 用户、模式、候选顺序、已完成项、当前进度 |
| 作答历史 | 时间、英文与释义选择、正确性、候选数、是否首次尝试、评价结果、唯一提交标识 |

切换用户不混用会话；刷新或网络重试不重复计分。查看详情和播放音频不写入成功复习。配置修改不突然重排已开始的一组。

## 7. 验收场景

- 选择两个不同用户，同一单词的错误、计划、进度互不影响。
- 两种模式均能完成一组；听音可重复播放且不会提前显示英文。
- 第一次答错、纠正答对后，失败记录仍存在。
- 最后一对可完成，但不被当作独立成功评价。
- 同组中文答案无重复；不足一组可正常结束。
- 练到一半刷新、离开再进入，恢复原有分组和进度，无重复累计。
- 今日总览能展示已有释义、音标和发音；查看不增加完成数。
- 到期复习按用户和模式分开安排，错误词之后可再次练习。
- 新词量与分组数量能配置，默认分别为 10 和 5。
